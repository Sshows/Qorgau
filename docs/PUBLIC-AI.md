# QORGAU AI: серверная интеграция

`POST /api/index?route=public-ai` вызывает OpenAI Responses API с сервера Vercel. Ключ не нужен фронтенду и не передаётся браузеру. Без ключа API возвращает HTTP 503 и «AI не подключён»; никакого локального генератора ответов нет.

В Vercel → проект qorgau-vision → Settings → Environment Variables добавить `OPENAI_API_KEY` для Production и выполнить новый деплой. Необязательная переменная `OPENAI_MODEL` заменяет модель по умолчанию `gpt-4.1-mini`. `AI_ENABLED=false` отключает запросы; эту переменную можно оставить незаданной. Наличие ключа означает настройку, а успешный ответ дополнительно зависит от корректности ключа, доступа к модели и баланса API.

Чат передаёт на сервер историю последних пяти обменов и новый вопрос. Ответ основан на текущем серверном снимке публичных источников и каталоге реальных камер. Учебные события исключаются. Источники и число использованных публикаций возвращаются вместе с ответом. Инструкции требуют различать время события, публикации и проверки, отмечать пропуски и цитировать первоисточники. Тексты источников обрабатываются как недоверенные данные. Это уменьшает риск выдуманных выводов, но не даёт гарантии безошибочности языковой модели.

Сервер валидирует роли сообщений и ограничивает диалог 12 сообщениями по 2000 символов, тело запроса — 100000 байт. OpenAI: `store:false`, максимум 1500 выходных токенов, тайм-аут 45 секунд. Клиентский тайм-аут — 58 секунд, лимит функции Vercel — 60 секунд. Ошибки и незавершённый ответ показаны явно. История находится только в памяти страницы.

Защита публичного обработчика: проверка Origin и Content-Type, лимит 3 запроса в минуту и 20 в сутки на IP **на экземпляр сервера**. Память экземпляра не является общим распределённым счётчиком; для ограничения расходов нужен бюджет проекта OpenAI или дополнительный общий rate-limit store при дальнейшем развитии. Для чтения общедоступных данных Supabase и вход в операторский кабинет не требуются.

Проверки `server/publicAi.test.ts` и HTTP-тест обработчика покрывают отсутствие ключа без вызова провайдера, исключение DEMO из контекста, реальные параметры запроса Responses, разбор ответа, неверные роли/размер истории, UTF-8 тело длинного диалога и квоты. Вызов настоящей модели **не проверен**, потому что владелец пока не добавил ключ. Тест с подменённым HTTP используется только в тестах и не является имитацией AI в приложении.

Официальные справочники: [Responses / text](https://developers.openai.com/api/docs/guides/text), [GPT-4.1 mini](https://developers.openai.com/api/docs/models/gpt-4.1-mini).
