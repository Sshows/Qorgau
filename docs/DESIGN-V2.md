# Новый интерфейс — этап 1, 3 ноября 2026

По выбору владельца сначала полностью переработан интерфейс; подключение настоящего AI переносится на следующий этап. Статус этого документа — отчёт о дизайне и проверенных сценариях, а не заявление о подключении базы или модели.

## Изменено

- Восемь основных страниц: Обзор, Карта, События, Видеонаблюдение, Аналитика, Отчёты, QORGAU AI, Настройки. Экспериментальная сцена перенесена в настройки.
- Новая тёмная компоновка с узкой боковой навигацией, голубыми акцентами, крупной спутниковой картой, компактными показателями, лентой событий и SVG-графиками.
- Показатели обзора открывают соответствующие события и статусы камер. Глобальный поиск ищет также районы, категории и источники.
- События получили отдельную страницу регистрации/редактирования и отдельную карточку с историей и переходом к карте. Поиск/фильтры сохраняются при возврате.
- Камеры: сетка и карта рядом, настоящие количества, фильтры восьми районов/типа/статуса/поиска, сброс, сортировка, список/карта/видеостена. Просмотр и паспорт камеры открываются отдельной страницей; есть возврат в каталог. Пагинация включается только при более чем 12 результатах.
- Координаты камер не выдуманы: для трёх потоков используется явно обозначенный общий ориентир Шымбулака. Схемы на обложках подписаны «не кадр с камеры».
- Карта: 2D/3D, спутник/улицы, поиск, районы с приближением и отбором объектов, карточки и переходы к событиям/камерам, слои зданий и дорог OSM.
- Аналитика: SVG-линии/области, реальные агрегаты, категории/районы/статусы/интервалы открывают отфильтрованный журнал. Отдельные параметры сохраняются при переходах.
- Отчёты: двухколоночный конструктор, выборка, столбцы, разделы, предпросмотр; реальные CSV и самостоятельный HTML-файл с выбранными данными. Маркировка DEMO обязательна; печать/PDF — через браузер.
- AI и настройки оформлены в общей системе. Подключение модели явно обозначено следующим этапом; поддельных ответов нет.

## Проверено

TypeScript, production build, 24 автоматических теста. Новые тесты покрывают переходы со статусом камер, сохранность фильтров при редактировании, поиск по району и источнику, фильтрацию отчётов по местным суткам, столбцы, CSV-формулы, HTML-экранирование, маркировку DEMO, пустую выборку и неверный период.

Браузерная приёмка:

| Сценарий | Результат |
| --- | --- |
| Показатель камер → каталог с выбранным статусом | Проверен; нулевая выборка честно показывает отсутствие результатов |
| Район Алмалинский / Медеуский → камеры и карта | Проверено: 0 / 3 камеры, карта меняет фокус |
| Камера → отдельная страница → запуск потока | Базовая станция воспроизводит видео; статус меняется только по playing |
| Камера без точных координат → карта | Открывается общий ориентир курорта и список его реальных камер |
| Создание учебного события | Появляется в журнале; изменение статуса отображается в истории |
| Возврат из редактирования | Поисковая строка сохраняется |
| Категория «Другое» в аналитике → журнал | Открывается одна созданная учебная запись |
| Отчёт по Бостандыкскому району | Скачаны CSV (3 строки) и HTML; исключённый столбец «Источник» отсутствует |
| Телефон 390×844 и планшет 820×1180 | Проверены компоновка, меню, каталог; горизонтального расширения страницы телефона нет |
| Настройки / AI | Страницы просмотрены; отсутствие подключений обозначено |

Кнопки и ссылки рассмотрены по группам: навигация, поиск, показатели, карточки, формы, фильтры, режимы каталога, карта, графики, экспорты и источники. Полный тест серверных ролей, реальных аккаунтов и моделей невозможен до подключения сервисов. Сохранение PDF через системный диалог ещё не принято как отдельный сквозной сценарий.

## Что остаётся

Учебные события сохраняются в браузере. Общая Supabase-база, реальные пользователи/роли и настоящий AI требуют внешнего подключения и последующей проверки. Серверный API, SQL/RLS и интеграция уже подготовлены; этот этап их не активирует.

Исследование OSIRIS и оригинальных источников: [CAMERA-RESEARCH.md](CAMERA-RESEARCH.md). Внешние кандидаты показаны отдельно от подключённого каталога и не увеличивают его счётчики. Дополнительные видеопотоки не объявляются проверенными по одному HTTP-манифесту или JPEG-превью.
