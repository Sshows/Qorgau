# QORGAU Vision · Алматы

Русскоязычный демонстрационный центр ситуационного обзора Алматы на React, TypeScript, Vite и CesiumJS. Открывается сразу на Алматы и работает без API-ключей.

## Запуск

Нужен Node.js 24.14+ (проверено на 24.19.0).

```sh
npm ci
npm run dev
```

Откройте http://localhost:4173. Для production: `npm run build`, для локальной проверки сборки: `npm run preview`. `npm test` проверяет поиск, координаты, расстояния и маркировку demo-данных. `predev` и `prebuild` автоматически копируют статические Cesium Workers/Assets из зависимости в `public/cesium`; папка не хранится в Git.

## Возможности

- Спутниковая карта Esri и улицы OpenStreetMap, 2D/3D, рельеф Re:Earth с запасным плоским режимом.
- Навигация по 8 районам, поиск по 8 ориентирам, demo-объектам и координатам внутри региона Алматы. Пример: `43.238, 76.945`.
- 800 реальных контуров OSM-зданий с экструзией и 500 линий дорог в центральном фрагменте города. Часть высот оценочная. Это не фотограмметрия и не полный набор зданий Алматы.
- 16 общедоступных отметок полиции из OSM; слой выключен по умолчанию. Их существование и режим работы не проверены; одна точка — приближённый центр контура.
- 5 вымышленных происшествий, 6 вымышленных камер и 4 учебных экипажа. Все они явно маркированы как демонстрационные.
- Отдельный слой публичных веб-камер Шымбулака: базовая станция, средняя станция, ледник Богдановича. Просмотр по нажатию через HLS-плеер; переключение, остановка и ссылка на официальный сайт. На карте одна приблизительная отметка курорта, не места установки камер.
- Кнопки «Пробки · 2ГИС» открывают актуальную дорожную карту Алматы около выбранного объекта или района. Данные пробок и дорожных сообщений внутри QORGAU пока не отображаются.
- Карточки объектов, ближайший demo-патруль по прямой, автомобильный маршрут OSRM с расстоянием и расчётным временем. Если сервис недоступен, показывается подписанная прямая линия. Никаких назначений экипажам не отправляется.
- Воспроизведение учебного сценария, фильтры происшествий и экспорт текущей сцены в JSON.

## Данные и границы прототипа

Проект не связан с МВД. В нём нет ведомственных баз, распознавания лиц, хранилища персональных данных, закрытых CCTV-потоков или live-патрулей. Публичные туристические камеры отделены от учебных объектов. Расчёт маршрутов не учитывает пробки. Районы заданы приблизительными точками навигации, не административными границами. Адресный поиск основан на неполном публичном справочнике OSM; AI-команды пока не реализованы. Все исходники и демонстрационные данные открыты для проверки.

Детали выгрузки OSM, точные запросы, даты, преобразования и лицензия: [public/data/SOURCES.md](public/data/SOURCES.md). Данные © OpenStreetMap contributors, ODbL 1.0. В приложении сохранены видимые credits поставщиков карты и рельефа.

Дорожные маршруты: [OSRM / FOSSGIS](https://routing.openstreetmap.de/about.html); запросы только по нажатию кнопки, ограничение 1 запрос/секунду и кеширование результатов. Встроенные ориентиры ищутся автономно; внешний поиск использует Photon. Публичный Nominatim не вызывается.

Источники камер и дорожной информации, результаты проверки и ограничения встраивания: [public/data/PUBLIC-SOURCES.md](public/data/PUBLIC-SOURCES.md). Три потока взяты из публичной страницы [Шымбулака](https://shymbulak.com/live/) и загружаются напрямую в браузер, без записи или ретрансляции. Внешние каталоги открываются ссылками. GEONET оставлен ссылкой с неподтверждённым статусом эфира и местом съёмки.

Собственная карта 2ГИС с пробками потребует личного API-ключа и подходящего доступа к Map Tiles API. Приложение не извлекает пользовательские дорожные сообщения или чужие ключи. Дизайн QORGAU самостоятельный, с привычными поиском, слоями и карточками.

## Поиск и проверка открытых источников

Кнопка «Поиск» в верхнем меню открывает четыре направления:

- **Профили:** один известный публичный ник; пять шаблонов ссылок из MIT-каталога Sherlock (GitHub, GitLab, Codeberg, DEV Community, Telegram). Только GitHub проверяется через публичный API. Остальные результаты явно отмечены «Не проверено» и открываются вручную. Совпадение ника не доказывает личность. Из ответа GitHub используются только `login`, `type`, `html_url`; биографии, email, адреса, фотографии и другие поля не отображаются и не сохраняются. Запросы выполняются только по кнопке, с тайм-аутом и обработкой ограничений API.
- **Телефон:** реально подключены `intl-tel-input` и официальный React-компонент, версия 29.5.0. Локальная проверка и формат E.164, страна плана нумерации и тип по справочнику. Нет передачи номера на сервер, поиска владельца, геолокации, текущего оператора или подтверждения существования SIM-карты. +7 — общий код нескольких стран; перенос номера и актуальность справочника ограничивают выводы.
- **Организации:** ручной поиск публичных организаций и адресов через Photon / OpenStreetMap в пределах `76.5,42.8,77.3,43.6`. До семи результатов, проверка координат и OSM-ссылок, тайм-аут 15 секунд, пауза между запросами и ограниченный кеш в памяти. Выбранный объект открывается на карте. Общественный API Photon не гарантирует доступность.
- **Город и дороги:** проверенные ссылки на Almaty Joly, канал акимата, новости gov.kz и дорожный слой 2ГИС. Это каталог первоисточников, не автоматическая новостная лента и не API-интеграция 2ГИС.

Полные CLI Sherlock, Maigret, GoSearch, OpenOSINT, Linkook и PhoneInfoga не установлены и не запускаются. Их массовый сбор, рекурсивное построение досье и поиск по утечкам не подключены. `awesome-falsehood` — справочник ошибочных предположений, не поисковый движок. CamPhish (поддельные страницы для получения камеры/GPS) исключён. Здесь нет доступа к чужим устройствам, поиска по базам МВД, утечкам, документам или домашним адресам.

История поиска не сохраняется в хранилище браузера и не включается в экспорт сцены; выбранный публичный объект карты может попасть в экспорт как городской объект. Ник отправляется непосредственно GitHub, адресный запрос — Photon, после явного нажатия. Телефон обрабатывается только локально. Шаблоны Sherlock: [`src/profileProviders.json`](src/profileProviders.json), лицензия: [`public/licenses/sherlock-MIT.txt`](public/licenses/sherlock-MIT.txt), исходный файл: [data.json](https://github.com/sherlock-project/sherlock/blob/master/sherlock_project/resources/data.json), SHA файла `d3f44240cc9d6b7fff543d6492e5be066ac06a58`, проверено 09.10.2026.

Официальность каналов: [публикация акимата](https://www.gov.kz/memleket/entities/almaty/press/news/details/613173?lang=ru). Документация: [GitHub public users API](https://docs.github.com/en/rest/users/users#get-a-user), [Photon](https://github.com/komoot/photon), [intl-tel-input](https://github.com/jackocnr/intl-tel-input).

## Архитектура и дизайн

Репозиторий изначально был пустым. Создан отдельный компактный интерфейс QORGAU в тёмной палитре оперативного центра. Идея слоёв и ситуационного обзора вдохновлена [God's Eye View](https://github.com/bilawalsidhu/gods-eye-view); исходный код и его сторонние наборы данных не копировались. Используется тот же открытый движок CesiumJS.

`src/MapView.tsx` управляет Cesium; `src/data.ts` хранит учебный каталог; `src/publicSources.ts` — публичные источники; `src/PublicCameraPlayer.tsx` — видеоплеер; `src/domain.ts` содержит функции поиска и расстояний; `src/services.ts` — публичный маршрут и чтение набора OSM; `src/App.tsx` — интерфейс.

## Публикация

Выбран Vercel: приложение статическое, серверная база и секреты не нужны. В репозитории есть `vercel.json`; Build Command — `npm run build`, Output Directory — `dist`, Node.js — 24.x. Публикуется проверенная сборка из этого репозитория. Изображения и рельеф загружаются с внешних публичных сервисов, их доступность зависит от сети и политики поставщиков.
