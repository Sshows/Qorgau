# QORGAU Vision · Алматы

Прототип ситуационного центра на React 19, TypeScript, Vite и CesiumJS. Сохраняет 2D/3D-карту и публичные источники предыдущей версии, добавляет событийную модель, Vercel Functions и подготовленную интеграцию PostgreSQL/PostGIS/Supabase Auth.

Опубликованная версия: https://qorgau-vision-mad.vercel.app/ — фронтенд и API на Vercel, пока в локальном DEMO. Сведения о выпуске: [docs/RELEASE.md](docs/RELEASE.md).

## Запуск
Node.js 24.x, `npm ci`. Два терминала: `npm run dev:api` и `npm run dev`. Открыть http://localhost:4173. Секреты передаются только окружению серверного процесса; `.env.example` — список имён. Vite frontend не получает ключи. `npm test` — 15 проверок, `npm run build` — TypeScript frontend/backend и сборка. В Vercel используется `api/index.ts` без отдельного сервера.

## Реализовано
- Главная панель с вычисляемыми показателями, последними событиями, картой и переходами в модули.
- Центр событий: создание/редактирование, категории/районы/приоритеты/статусы, источник, дата Алматы, выбор точки карты, фильтры, история, конфликт версий.
- Камеры: каталог и поиск, 8 районов, тип/статус, сортировка, список/сетка/карта, видеостена до 4 потоков, создание/редактирование настроек администратором. Доступность подтверждается воспроизведением в текущей сессии браузера.
- Cesium 2D/3D, OSM/спутник, здания/дороги, события/камеры/ориентиры, кластеризация от 8 близких объектов, локальный и адресный поиск Photon.
- Аналитика: категории, районы, статусы, дни/недели с нулевыми интервалами, сравнение двух периодов.
- Отчёты с выбором показателей, таблицей, CSV и печатью/сохранением PDF.
- Серверный AI через OpenAI Responses, снимок данных и основания ответа, ошибки, серверный ключ, квоты. Включается только после настройки базы/авторизации/модели и разрешения расходов.
- Серверные роли admin/operator/observer, HttpOnly cookie, Origin-проверки, валидация, RLS, триггерный журнал событий/камер/ролей. Нет открытых паролей или service-role ключа.
- Предыдущая учебная сцена, маршруты, патрули, публичные отметки полиции OSM, профили/форматирование телефона сохранены отдельно в экспериментальном разделе.

## DEMO и реальные подключения
Без настроек Supabase приложение запускает **локальное DEMO**. Записи сохраняются в одном браузере; это не серверная база. Реальные происшествия автоматически не поступают. Три исходных потока Шымбулака сохранены без заявления об их текущей доступности. Непроверенные каталоги находятся в источниках, не выдаются за подключённое видео. Тепловая карта не активирована без достаточного подтверждения координат.

Для общей базы/входа нужны `SUPABASE_URL`, `SUPABASE_ANON_KEY` и SQL-миграция. Для AI дополнительно `OPENAI_API_KEY`, `OPENAI_MODEL`, `AI_ENABLED=true`. Никакие платные сервисы автоматически не создаются. Реальную базу и AI нужно проверить после подключения.
