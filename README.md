# QORGAU Vision · Алматы

Прототип ситуационного центра на React 19, TypeScript, Vite и CesiumJS. По умолчанию открывается **режим реальных публичных источников**: карта Алматы, публикации официальных источников, каталог публичных камер, аналитика полученного снимка и серверный AI-интерфейс. Для этого режима Supabase и вход пользователя не требуются.

Сайт: [qorgau-vision-mad.vercel.app](https://qorgau-vision-mad.vercel.app/). Фронтенд и API размещаются в одном Vercel-проекте. Проверки конкретного выпуска и фактического просмотра камер приводятся в отчёте о выпуске; наличие источника в каталоге само по себе не означает, что видео сейчас воспроизводится.

## Локальный запуск

Нужен Node.js 24.x. Установить зависимости:

```sh
npm ci
```

Запустить в двух терминалах:

```sh
npm run dev:api
```

```sh
npm run dev
```

Открыть [localhost:4173](http://localhost:4173). Локальный API работает на `127.0.0.1:4174`, Vite перенаправляет `/api` к нему. Без ключей доступны карта, публичные публикации и каталог камер. Для загрузки внешних источников нужен доступ в интернет.

```sh
npm test
npm run build
```

Тесты проверяют обработку публичных источников, даты и координаты, кеш, ошибки, происхождение данных, фильтры, экспорт, каталог камер, API и подготовленный AI-адаптер. Сборка проверяет TypeScript фронтенда и бэкенда. Реальная работа сторонних потоков дополнительно проверяется в браузере.

## Публичные данные и карта

`GET /api/index?route=public-data` автоматически получает данные шести источников:

| Источник | Подключение | Содержание |
| --- | --- | --- |
| ДЧС Алматы | Публичная HTML-лента Telegram | Тематические публикации канала, включая пересланные сообщения |
| МЧС Казахстана | Официальный RSS | Новости и предупреждения |
| Акимат Алматы | Официальный RSS | Городские сообщения и дорожные ограничения |
| КНДЦ | Публичный JSON виджета официального бюллетеня | Предварительные параметры сейсмических событий |
| USGS | Документированный GeoJSON API | Землетрясения в радиусе 100 км от Алматы за 30 дней |
| OSIRIS | Документированный публичный сейсмический API | Слой USGS с тем же географическим фильтром и удалением дубликатов |

Серверный кеш и автоматическое обновление открытой страницы — **5 минут**. Повторные одновременные запросы объединяются; используются фиксированный список HTTPS-адресов, тайм-ауты, ограничение размера ответа и проверка структуры. Для каждого источника видны последняя проверка, последнее успешное обновление, количество записей и ошибка. При сбое может сохраняться явно отмеченный предыдущий успешный снимок до 24 часов.

Время события, публикации и проверки хранится отдельно. Отметка «свежая» означает возраст источниковой даты до 72 часов, а не действующее происшествие. Более старые публикации обозначены архивными. Координаты и время события не восстанавливаются из догадок: публикации без координат остаются в списке без маркера. Количество публикаций не равно количеству происшествий; пустая выборка не доказывает отсутствие происшествий в городе.

Карта поддерживает обычную и спутниковую подложки, 2D/3D, перемещение, масштабирование, поиск адресов и объектов, фильтрацию и карточки выбранных объектов. Рабочая карта не получает учебные происшествия. Происхождение, реальные URL, ограничения и результаты проверки источников: [docs/LIVE-SOURCES.md](docs/LIVE-SOURCES.md).

## Публичные камеры

Исследованы **28 конкретных источников**, в каталог включены **27: 20 HLS-видео и 7 обновляемых снимков**. YouTube-трансляция исключена после проверки: запись недоступна у владельца. Покрытие включает Алматы, Алматинскую область, Актау, Караганду, Семей и Восточно-Казахстанскую область. Числа рассчитываются из записей каталога, а не из рекламных счётчиков сторонних сайтов.

Доступны поиск, фильтры города/региона, района, категории, формата и доступности, избранное, сетка, список, видеостена, карта, увеличенный просмотр и переход к следующей камере. Источники без подтверждённых координат не получают искусственные точки на карте. У опубликованных каталогом координат указано их происхождение и ограничение точности.

Успешный запрос HLS-манифеста или сегмента подтверждает транспортную доступность, а не воспроизведение. Статус видео становится «Доступна» после события `playing` в текущем браузере. Успешная загрузка снимка означает доступность изображения; это не прямой видеопоток и не гарантия свежести съёмки. Поддержка внешнего YouTube-плеера сохранена, но известная недоступная запись не участвует в каталоге и показателях. Публичный HLS может подключаться до 90 секунд; просмотр можно отменить. Если просмотр нельзя встроить, используется исходная страница владельца; ограничения доступа не обходятся.

Конкретные камеры, первоисточники, форматы, транспортные проверки и ограничения: [docs/CAMERAS-LIVE.md](docs/CAMERAS-LIVE.md).

## QORGAU AI

Отдельный чат хранит историю текущего диалога в памяти страницы, показывает загрузку, ошибки и основание ответа. `POST /api/index?route=public-ai` получает снимок публичных событий, состояние источников и реальный каталог камер на сервере и вызывает OpenAI Responses API. Учебные данные исключаются; ключ не передаётся клиенту. До подключения ключа отображается **«AI не подключён»**, сервер возвращает 503, ответы не имитируются.

Серверные переменные окружения:

| Переменная | Назначение |
| --- | --- |
| `OPENAI_API_KEY` | Обязательна для настоящих ответов AI; хранить только в Vercel Environment Variables или окружении локального API-процесса |
| `OPENAI_MODEL` | Необязательна; по умолчанию `gpt-4.1-mini` |
| `AI_ENABLED` | Необязательный выключатель: значение `false` отключает AI; при наличии ключа пустое/отсутствующее значение разрешает запросы |

После добавления переменных в Vercel нужен новый деплой. Файл `.env.example` перечисляет имена; локальному API переменные нужно передать в окружение процесса. Не использовать префикс `VITE_` для секретов и не добавлять заполненные значения в GitHub.

Запрос к модели выполняется по кнопке пользователя, с `store: false` и ограничением длины ответа. Лимит публичного маршрута — 3 вопроса в минуту и 20 в сутки на IP **на экземпляр сервера**; это не глобальный лимит расходов. Настроить бюджет проекта OpenAI отдельно. Наличие ключа подтверждает настройку, а доступность модели и баланса проверяется фактическим запросом. Публичному AI не нужны Supabase и операторская авторизация.

## Учебный режим и дополнительный операторский контур

**DEMO включается только отдельной кнопкой.** Учебные события, патрули и предыдущая экспериментальная сцена изолированы от публичного режима. После перезагрузки приложение снова открывает публичные данные. Сбой источника не подменяет их учебными записями.

Сохранены подготовленные API и модель для ручных операторских записей с Supabase PostgreSQL/PostGIS и Auth: роли `admin/operator/observer`, HttpOnly cookie, проверка Origin, RLS, журнал и контроль версий. Это **необязательный отдельный контур**. Для него нужны `SUPABASE_URL`, `SUPABASE_ANON_KEY` и ручное применение SQL из `supabase/migrations`; публичные ленты и камеры от него не зависят. DEMO-записи не импортируются в общую базу автоматически. Развёртывание базы, назначение ролей и проверку прав выполнить до использования реальных служебных записей. Приложение не использует service-role key.

## Деплой

Сохранить в Vercel Node.js 24.x, Framework Preset Vite, Build Command `npm run build`, Output Directory `dist`. `api/index.ts` работает как Vercel Node.js Function; отдельный постоянно запущенный сервер не нужен. `vercel.json` исключает `/api` из SPA rewrite.

Перед продвижением выпуска проверить сборку и Preview, затем опубликовать проверенную версию в существующий проект. Проверить, что `/api/index?route=health` возвращает JSON с `mode: "public"` и `publicAi`, а `/api/index?route=public-data` — снимок и состояния источников. Проверить фактическую карту, ссылки и выбранные камеры в браузере. SQL-миграции не запускаются во время build. Предыдущий deployment остаётся вариантом отката.

`src/App.tsx` выбирает публичный или явно включённый учебный режим; `LiveWorkspace.tsx` — публичный интерфейс; `liveData.ts` — модель публичных публикаций; `cameraCatalog.ts` — конкретные источники камер; `server/publicSources.ts` — агрегатор лент; `server/publicAi.ts` — серверный AI; `server/handler.ts` — маршруты API; `supabase/migrations` — необязательная операторская база.

Это технологический прототип, не официальная система МВД и не полный реестр происшествий. Закрытые полицейские камеры, ведомственные источники и идентификация людей не подключены.
